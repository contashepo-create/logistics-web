# المميزات الإضافية — الفاتورة الضريبية والمستخدم الإضافي

## ترقية قاعدة موجودة

نفّذ الملف التالي كاملاً في **Supabase Dashboard → SQL Editor**:

`supabase/migration_extra_features_users_v11.sql`

الترحيلة آمنة عند إعادة التشغيل، ولا تفعّل أي ميزة لأي شركة موجودة. غياب سجل التفعيل يعني أن الميزة متوقفة.

## إعداد الخادم المطلوب للمستخدم الإضافي

إنشاء بريد مؤكد وكلمة مرور يحتاج Supabase Auth Admin API. لذلك يجب ضبط السر التالي في بيئة الخادم فقط:

`SUPABASE_SERVICE_ROLE_KEY`

لا تستخدم بادئة `NEXT_PUBLIC_` ولا تضع المفتاح في المتصفح. بعد ضبطه، أعد نشر التطبيق.

## السلوك الافتراضي

- `tax_invoice`: متوقفة، ويُمنع QR مهما كانت إعدادات الطباعة القديمة.
- `additional_user`: متوقفة، وتُفعّل تلقائياً عند إنشاء المستخدم من لوحة المطوّر.
- كل شركة لها مالك واحد ومستخدم إضافي واحد كحد أقصى.
- تعطيل المستخدم الإضافي يمنع وصوله في الواجهة وفي سياسات RLS.
