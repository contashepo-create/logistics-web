# المميزات الإضافية — الفاتورة الضريبية والمستخدم الإضافي

## ترقية قاعدة موجودة

نفّذ الملف التالي كاملاً في **Supabase Dashboard → SQL Editor**:

`supabase/migration_extra_features_users_v11.sql`

الترحيلة آمنة عند إعادة التشغيل، ولا تفعّل أي ميزة لأي شركة موجودة. غياب سجل التفعيل يعني أن الميزة متوقفة.

## إعداد الخادم المطلوب للمستخدم الإضافي

إنشاء بريد مؤكد وكلمة مرور يحتاج Supabase Auth Admin API. لذلك يجب ضبط السر التالي في بيئة الخادم فقط:

`SUPABASE_SERVICE_ROLE_KEY`

لا تستخدم بادئة `NEXT_PUBLIC_` ولا تضع المفتاح في المتصفح. بعد ضبطه، أعد نشر التطبيق.

## خطأ «تعذّر إنشاء الحساب بسبب قيود قاعدة البيانات»

إذا ظهرت هذه الرسالة عند إضافة مستخدم إضافي، نفّذ:

`supabase/migration_fix_additional_user_creation_v24.sql`

**السبب:** المشغّل `trg_auth_users_signup_metadata` على `auth.users` كان يطبّق تحققات
تسجيل *صاحب الشركة* (تفرّد الهاتف عالمياً + اسم الشركة + عنوان المسؤول + السنة
المالية) على المستخدم الإضافي أيضاً، فيفشل الإدراج وتحوّله GoTrue إلى الرسالة
العامة `Database error creating new user`.

الترحيلة v23 حاولت استثناء المستخدم الإضافي عبر
`raw_app_meta_data.managed_by_developer`، لكن **GoTrue لا تكتب `app_metadata`
أثناء الإدراج**: تُدرج الصف أولاً ثم تُحدّثه بـ `UPDATE` منفصل
([supabase/auth#975](https://github.com/supabase/auth/issues/975))، فتبقى القيمة
`false` داخل المشغّل ولا يسري الاستثناء.

**الحل في v24:** «تذكرة إنشاء» خادمية في جدول `public.managed_signups` يكتبها
مسار `/api/zerocold/company-users` بمفتاح الخدمة قبل استدعاء `createUser`،
ويقرأها المشغّل بالبريد — وهي قيمة متوفّرة فعلاً وقت الإدراج. التذكرة تُستهلك
مرة واحدة وتنتهي خلال 15 دقيقة، والجدول عليه RLS بلا سياسات ولا صلاحيات
لـ `anon`/`authenticated`، فلا يمكن تزويرها من المتصفح.

كما تسمح v24 للمستخدم الإضافي بمشاركة هاتف شركته وبريدها، مع بقاء تفرّد
البريد والهاتف بين الحسابات صارماً.

## السلوك الافتراضي

- `tax_invoice`: متوقفة، ويُمنع QR مهما كانت إعدادات الطباعة القديمة.
- `additional_user`: متوقفة، وتُفعّل تلقائياً عند إنشاء المستخدم من لوحة المطوّر.
- كل شركة لها مالك واحد ومستخدم إضافي واحد كحد أقصى.
- تعطيل المستخدم الإضافي يمنع وصوله في الواجهة وفي سياسات RLS.
