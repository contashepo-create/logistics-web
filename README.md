# 🚛 النظام المحاسبي المتكامل لشركة النقل — نسخة الويب (متعددة الشركات)

نسخة ويب كاملة من تطبيق سطح المكتب `contashepo-create/logistic` (Python + PySide6 + SQLite)،
مبنية بـ **Next.js + React + TypeScript + Supabase** بواجهة عربية RTL عصرية، مع
**عزل كامل عبر company_id** و**اشتراك واحد** و**ضريبة قيمة مضافة**.

---

## ✨ المميزات

### منقولة مطابقة للمصدر
- **فواتير النقل:** رأس فاتورة + نقلات (سيارة/سائق/من/إلى/سعر) + مصروفات مباشرة (تريب/بنزين/كارتة/أخرى) + مرفقات.
- **سندات قبض** (تحصيل من عميل / إيرادات أخرى) و**سندات دفع** (رحلة / سلفة / سيارة / عام).
- **الرواتب:** الأساسي + الإضافات − خصم السلف (مع جدول السلفيات المتاحة) − الخصومات الأخرى.
- **السنوات المالية** مع لقطة إغلاق Snapshot، وكل قواعد المنع المحاسبي (سنة مفتوحة، حذف مرتبط، سلف ≤ المتبقي…).
- **التقارير الخمسة** + كشوف الحساب (عميل / خزينة / بنك) + الأرصدة اللحظية + تصدير Excel/PDF/طباعة.

### إضافات جديدة (بناءً على طلبك)
- **🔐 تسجيل دخول + إنشاء حساب** (Supabase Auth بالبريد وكلمة المرور) + صفحة تأسيس الشركة.
- **🏢 عزل كامل عبر `company_id`:** وحدة العزل هي **الشركة** وليس المستخدم. كل جدول بيانات يحمل
  `company_id` مع حارس خادمي يفرضه عند الإدراج + سياسات RLS — لا يمكن لأي شركة رؤية أو تعديل بيانات أخرى بأي طريقة.
- **💳 اشتراك واحد (بدون باقات/أدوار):** كل شركة لها اشتراك واحد بنوع (شهري / سنوي / **مفتوح بلا تحديد**)
  يتحكم فيه المطوّر من لوحة التحكم. انتهاء الاشتراك أو إيقاف الشركة يمنع الوصول فوراً.
- **🛡️ لوحة المطوّر** (`/admin`) مرتبطة حصرياً بالبريد `conta.moha@gmail.com`:
  نظرة عامة + **إدارة الشركات والاشتراكات** (بحث، تفعيل/إيقاف، تعيين نوع الاشتراك ومدته، ملخص نشاط، حذف شركة)
  + **سجل نشاط** (audit log).
- **🧾 ضريبة القيمة المضافة:** نسبة قابلة للتعديل (افتراضي 15%) تظهر في الفاتورة (قبل/شامل الضريبة).
  الفواتير **مرجعية فقط** — غير مرتبطة بـ ZATCA.
- **🎨 تصميم عصري** مستوحى من pro-acc: شريط جانبي داكن متدرّج، بطاقات بظلال ناعمة، زوايا دائرية، نظام ألوان حديث.

> النظام محاسبي **بسيط** بطبيعته: لا شجرة حسابات ولا قيود يومية. الأرصدة تُشتق من الحركات تلقائياً.

## 🚀 التشغيل

### 1. المتطلبات
- Node.js 18+ (مُختبر على 22) — حساب Supabase.

### 2. التثبيت والبيئة
```bash
npm install
cp .env.example .env.local   # ثم ضع رابط ومفتاح anon الخاصين بك
```

### 3. إعداد قاعدة البيانات (مرة واحدة)
افتح **Supabase Dashboard → SQL Editor** والصق محتوى
[`supabase/schema.sql`](supabase/schema.sql) كاملاً ثم **Run**.
> للترقية من نسخة أحادية الشركة قائمة استخدم [`supabase/migration_auth_vat.sql`](supabase/migration_auth_vat.sql).

### 4. بيانات تجريبية (اختياري)
```bash
npm run seed
```
> أنشئ أولاً المستخدم `demo@example.com` أو عطّل «Confirm email» في Supabase ليتمكن السكربت من تسجيل الدخول.

### 5. التشغيل
```bash
npm run dev     # التطوير
npm run build && npm start   # الإنتاج
```

## 🔑 الحسابات والأدوار

| الحساب | الدور | الوصول |
|---|---|---|
| أي مستخدم يسجّل | مالك شركة | شركته المعزولة فقط (كل الأقسام) |
| `conta.moha@gmail.com` | مطوّر | لوحة المطوّر `/admin` (كل الشركات والاشتراكات) |

لا يوجد نظام أدوار/صلاحيات داخل الشركة ولا باقات متعددة — **اشتراك واحد** لكل شركة (شهري/سنوي/مفتوح).
يُعرَّف المطوّر بالبريد في دالة `is_admin()` بالمخطط وثابت `ADMIN_EMAIL` في `src/lib/auth.ts` (يجب أن يتطابقا).

### تعطيل «تأكيد البريد» (للتجربة المحلية)
Supabase Dashboard → Authentication → Providers → Email → عطّل **Confirm email**.
عند التفعيل، سيظهر للمستخدم صفحة «تحقق من بريدك» بعد التسجيل.

## 🔒 الأمان (مشدّد)

- **عزل عبر `company_id`:** عمود `company_id` في كل الجداول + حارس `set_company_id()` يفرض القيمة من جلسة
  المستخدم عند الإدراج (لا يمكن تزويرها من العميل) + سياسات RLS `company_id = auth_company_id()`.
- **اشتراك وحالة الشركة:** شرط `is_company_active()` في RLS (اشتراك ساري + شركة مفعّلة) — يمنع أي وصول عند
  الانتهاء أو الإيقاف حتى من خارج الواجهة.
- **منع التلاعب بالبيانات الحساسة:** مالك الشركة يعدّل بيانات شركته التشغيلية فقط (الاسم/الهاتف/الضريبة)
  وليس الاشتراك أو الحالة — هذان عبر دوال المطوّر المحمية حصراً.
- **دوال `SECURITY DEFINER`:** كل دوال الإدارة تفحص `is_admin()` داخلياً و`search_path` مُقيّد.
- **أقل امتياز:** `anon` بلا امتيازات على الجداول؛ التسجيل وإنشاء الشركة عبر دالة `register_company` حصراً.
- **سجل نشاط:** تسجيل التسجيلات وإجراءات المطوّر.
- **ترقية قائمة:** [`supabase/migration_company_id.sql`](supabase/migration_company_id.sql).



- **العزل:** عمود `user_id` (مرجع إلى `auth.users`) في كل الجداول + سياسات RLS
  (`user_id = auth.uid()` + سياسة `is_admin()` للمطوّر + `is_active_user()` لإيقاف الحسابات).
- **الضريبة:** `invoices.vat_rate` لقطة للنسبة وقت الإنشاء؛ `vat_amount = subtotal × rate`؛
  ورصيد العميل وكشف الحساب يشملان الضريبة؛ تقرير P&L يُظهر الضريبة كبند مرجعي (ليست ربحاً).
- **المرفقات:** تُرفع إلى Storage bucket باسم `attachments` (أنشئه واجعله Public)؛ عند غيابه يُحفظ اسم الملف فقط.
- **PDF بالعربية:** `html2canvas + jsPDF` لدعم النص العربي RTL.
- **تسلسل الأرقام:** `MAX(number)+1` لكل مستخدم على حدة (عزل كامل للتسلسلات).
